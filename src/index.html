ValueEdge Beautifier v2.1.1
Extra UX polish for ValueEdge — inspired by Atlassian JIRA.
Features
✨
AI Proofread CommentsNew
Click ✨ Proofread below the comment box to improve your comment with AI. Review the original and improved versions side-by-side, edit either pane, then hit Use improved to apply.
💾
Save comments as drafts
Save and restore comment drafts from local storage. Each ticket keeps its own draft — nothing gets mixed up.
🎨
Colour-coded phase badges
Phase labels become colour-coded badges across all views.
